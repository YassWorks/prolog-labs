# Prolog Assignments

![Prolog](https://img.shields.io/badge/Prolog-Programming-purple)

This repository contains various Prolog assignments and examples for learning Prolog programming.

## Contents

- `assignment1.pl` - Basic Prolog concepts
- `assignment2.pl` - List operations
- `assignment2_part2.pl` - Additional list exercises
- `assignment3.pl` - Mathematical functions
- `assignment4.pl` - Advanced topics
- `bt.pl` - Binary trees
- `lists.pl` - List manipulation utilities
- `math.pl` - Mathematical predicates
- `s_numbers.pl` - Number-related predicates

## Getting Started

To run these Prolog files, you'll need a Prolog interpreter like SWI-Prolog.

```bash
swipl assignment1.pl
```
